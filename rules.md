# Website Rules

For consistency purposes, refer to this.

## Colors

- Every color has to be from [this palette](https://coolors.co/6f4e37-c19a6b-e0b98e-fed8b1-ffefd5): a warm, coffee/beige theme.
- coffee-bean: #6f4e37
- camel: #c19a6b
- tan: #e0b98e
- soft-apricot: #fed8b1
- papaya-whip: #ffefd5

## Animations

- Always use cubic-bezier(0.87, 0, 0.13, 1) unless it doesn’t make sense to.

## Look

- Assets should follow a parallaxing rule, where, if on top of another object, use a subtle drop shadow; otherwise, stay flat.
- Example: bg, mg, and fg -> bg:background, mg:settings, loading, and small-text, fg:dropdown menus.
- Drop shadow color should be the darker color on which the element is ontop of
- use something similar to box-shadow: -3px 3px 6px rgba(111, 78, 55, 0.2);

## Formatting

- Always round numbers to .1 +/- unless it doesn’t make sense to (like the ease anim)
- Use prettier formatting

## Other

- Always use a lightweight approach
